# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-02-15

### Added
- Initial release of HR Management System
- Complete MVC architecture with PHP 8+
- Arabic RTL interface with professional design
- Employee management module
- Department management
- Attendance tracking system
- Leave management with approval workflow
- Payroll management with PDF payslips
- Documents management with upload/download
- Backup and restore system with AES-256 encryption
- Multi-role user management (Admin, HR, Manager)
- Dashboard with statistics and charts
- Export to PDF and Excel functionality
- Responsive design with Bootstrap 5 RTL
- CSRF protection and security features
- Iraqi Dinar (IQD) currency support

### Features
- ✅ Employee CRUD operations
- ✅ Photo and document uploads
- ✅ Daily attendance tracking
- ✅ Leave requests and approvals
- ✅ Salary calculations
- ✅ Encrypted backups
- ✅ Role-based permissions
- ✅ Interactive charts
- ✅ Responsive mobile design

### Security
- Password hashing with bcrypt
- CSRF token protection
- SQL injection prevention
- XSS filtering
- File upload validation
- Session security
